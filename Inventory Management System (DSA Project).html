Data structures used

  • Hash map: SKU lookup, add and duplicate check in O(1) average.
  • Binary search tree: keeps products sorted by name. Insert, delete and prefix search in O(h); in-order traversal gives the sorted list in O(n).
  • Min-heap: finds the lowest-stock items. Build in O(n), extract the k smallest in O(k log n).
  • Stack: undo for add, delete and quantity changes in O(1).
